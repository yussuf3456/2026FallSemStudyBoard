# Fall 2026 Study Board

A one-page study tracker for the Fall 2026 term. It has a daily checklist of classes to attend, lecture videos to watch and study blocks, plus an Exams tab with a review page for each midterm and final.

Open `index.html` in a browser, or view the hosted copy on GitHub Pages: https://yussuf3456.github.io/2026FallSemStudyBoard/

Ticks are saved in your browser (localStorage), so each browser keeps its own progress.
